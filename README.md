# TasquesApp - Alex

## Descripció

TasquesApp és una aplicació web desenvolupada amb Angular que permet gestionar tasques personals.
L'objectiu del projecte és crear una eina senzilla per organtitzar activitats, afegir noves tasques i mantener un control de les pendents.

## Stack Tècnic

El projecte utilitza les següents tecnologies:

- Angular 18
- Arquitectura Standalone
- SCSS per als estils
- Angular CLI
- TypeScript
- Node.js i npm
- Git i GitHub per al control de versions
